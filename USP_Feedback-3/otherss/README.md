# USP Complaint & Feedback Management System

## 📋 Overview
A complete web-based Complaint & Feedback Management System built with PHP, MySQL, HTML5, CSS3, Bootstrap 5, and JavaScript.

## 🎯 System Modules

### 1. **User Module**
- User Registration & Login
- Submit Complaints
- View Complaint Status
- Receive Replies

### 2. **Admin Module**
- Admin Dashboard
- View All Complaints
- Assign to Staff
- Generate Reports
- Manage Users & Staff

### 3. **Staff Module**
- View Assigned Complaints
- Resolve Complaints
- Update Status
- Add Solutions

## 🛠️ Technologies Used
- **Backend**: Core PHP
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Server**: Apache (XAMPP/WAMP)
